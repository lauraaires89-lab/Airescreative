# Aires — Proyecto Portafolio

Esta es nuestra carpeta de trabajo. Todo lo que construyamos para el portafolio vive acá, organizado así:

```
aires-portfolio/
├── assets/
│   ├── images/        → logo, isotipo, foto, texturas de referencia
│   └── fonts/          → Archivo, Unbounded, Space Grotesk (para uso en Illustrator/Photoshop si los necesitas)
├── styleguide/
│   └── index.html      → LA GUÍA DE ESTILO — ábrela en tu navegador
└── README.md            → este archivo
```

## Cómo ver la guía de estilo

1. Descarga la carpeta completa (te la dejo en un .zip).
2. Abre `styleguide/index.html` haciendo doble clic — se abre directo en tu navegador (Chrome, Safari, el que uses). No necesitas instalar nada.
3. Tiene scroll, animación de fondo y hover en los botones/tarjetas — todo funciona ya, sin subir nada a internet todavía.

## Qué es esto exactamente

Es la base visual de todo lo que viene después: paleta de color, tipografía, el tratamiento de "ondas" que pediste, y cómo se van a ver el logo, tu foto, los botones y las tarjetas de proyecto. Antes de construir las páginas reales del portafolio, quiero que me digas qué te gusta y qué cambiarías acá — así no repetimos ajustes en cada página después.

## Próximos pasos (cuando apruebes la guía)

1. Definir la estructura de páginas (¿una sola página larga, o Home + páginas por proyecto?)
2. Elegir qué proyectos entran y conseguir las imágenes en buena resolución
3. Construir el sitio completo con esta misma base visual
4. Publicarlo — te explico las opciones (Vercel/Netlify) cuando lleguemos ahí, es literalmente arrastrar una carpeta y ya

## Cómo seguimos trabajando

No necesitas saber de código para nada de esto. Tú me das dirección y contenido (imágenes, textos, qué te gusta/no te gusta), yo construyo y ajusto el código. Cuando quieras un cambio, simplemente dímelo como me dices los cambios del CV.
